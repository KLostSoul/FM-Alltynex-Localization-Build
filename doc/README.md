# 문서 안내

처음 빌드하거나 번역을 편집하는 경우에는 한글 빌드 안내부터 읽습니다. 게임 내부의 출력 경로와 주소를 확인하려면 소스 분석을 참고합니다.

| 하고 싶은 작업 | 읽을 내용 |
| --- | --- |
| 처음 빌드하기 | [한글 빌드: 시작하기](Alltynex-Korean-Build.md#1-시작하기) |
| 번역·공백·X좌표 수정 | [CSV와 편집 규칙](Alltynex-Korean-Build.md#3-번역-csv와-편집-규칙) |
| 한글 출력 원리 이해 | [FNT와 조합 토큰](Alltynex-Korean-Build.md#4-fnt조합-토큰음절-합성) |
| 원본의 EGB·SPR 경로 확인 | [소스 분석: 문자 출력](Alltynex-Source-Analysis.md#문자비트맵-출력-규약과-호출-레코드) |
| 메모리 수정과 검증 근거 확인 | [메모리 배치](Alltynex-Korean-Build.md#6-메모리-배치와-엔딩-보호-예외), [검증 결과](Alltynex-Korean-Build.md#7-검증-결과와-한계) |

## 두 문서의 역할

**[한글 빌드](Alltynex-Korean-Build.md)**는 현재 패치의 사용과 구현을 설명합니다. 준비·빌드·편집 방법을 앞에 두고, 후크·슬롯·메모리 수정 근거와 검증값은 뒤에서 다룹니다.

**[소스 분석](Alltynex-Source-Analysis.md)**은 원본 게임의 구조를 설명합니다. 용어와 전체 흐름을 먼저 제시하며, 함수 주소·자료 형식·원문 대조표를 주제별로 제공합니다. 그래픽·객체·음원 자료는 상세 표로 제공합니다.


도구별 안내: [빌드 도구](../tools/README.md), [조합 토큰표](../Import/Strings/README.md).
